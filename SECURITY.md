# Segurança

- Não registre senhas, tokens, connection strings ou documentos sensíveis em issues e commits.
- Use uma `JWT_SECRET` longa e exclusiva.
- Restrinja `FRONTEND_URL` aos domínios oficiais.
- Crie usuários individuais; evite compartilhar a conta de administrador.
- Revise os perfis de acesso periodicamente.
- Faça exportações e backups periódicos do banco Neon conforme o plano contratado.
- Links de documentos devem apontar para armazenamento privado com controle de acesso quando houver dados pessoais ou fiscais.
